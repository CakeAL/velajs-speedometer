# 速度计

Xiaomi Vela JS 速度计：实时速度、经纬度、GPS 海拔和水平定位精度。主界面突出显示大号速度数字和海拔，点击「详情」查看经纬度和定位精度，点击速度单位切换 km/h、m/s、mph，点击「暂停」停止定位。

## 开发与构建

```sh
npm install
npm run start
npm test
npm run build
```

调试包生成到 `dist/com.cakeal.speedometer.debug.1.0.0.rpk`。发布构建使用 `npm run release`，正式分发前需要配置自己的签名。

## 测速实现

测速流程参考用户提供的「腕上时速」1.0.6：进入前台同时执行一次 `geolocation.getLocation`（60 秒超时）和持续 `geolocation.subscribe`，直接读取设备返回的 `speed`。m/s 乘以 3.6 转换为 km/h，低于 0.5 km/h 归零，内部保留一位小数，主界面默认显示整数时速。

速度、经纬度和海拔分别校验，坐标缺失不会阻止有效速度显示。首次未获得数据或字段缺失显示 `--`；已有速度超过 5 秒没有更新则归零，并标注等待更新。超过 15 秒未更新的坐标和海拔显示 `--`。不通过坐标差分估算速度，也不把经纬度转换为地图坐标。

暂停、页面隐藏和退出时取消订阅，忽略旧请求的迟到回调。测速页面保持屏幕常亮，暂停或退出后释放常亮设置；常亮接口不可用不影响测速。

## 设备范围与真机验证

仅面向带 GPS 且向 Vela JS 应用开放 `system.geolocation` 的设备。GPS 硬件存在不代表应用可调用定位接口，具体以[官方支持明细](https://iot.mi.com/vela/quickapp/zh/features/system/geolocation.html)为准，不适配没有 GPS 的设备，也不覆盖其他操作系统的手表。

根据 `device.getInfo` 返回的屏幕形状和比例选择圆屏、方屏或窄屏布局；圆屏保留上下安全边距，窄屏纵向排列经纬度和按钮。布局适配不等同于完成所有机型实测。

真机上允许精确定位权限并开启 GPS，在室外开阔处等待首次定位。检查静止与移动时的速度、经纬度和海拔，再检查暂停/继续、单位切换及退出后的定位释放。用户已确认当前模拟器的 GPS 测试不可靠，因此模拟器结果不能替代真机验证。
