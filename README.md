# 速度计 · Speedometer

Xiaomi Vela JS GPS 速度计，配套 AstroBox 插件同步、管理和导出 GPX 轨迹。应用与插件版本均为 **1.0.0**，支持圆屏、方屏和窄屏布局。  
可以用来没事记录一下你所乘坐的交通工具（公交车/出租车/轻轨/有轨电车/地铁（地上段））的速度，以及gpx轨迹。

## 安装

- **设备要求**：带 GPS，且向 Vela JS 应用开放定位接口的手表／手环。
- **手表端**：使用适配设备的快应用安装工具安装 `dist/com.cakeal.speedometer.debug.1.0.0.rpk`，打开速度计并允许定位权限。
- **手机端**：使用 AstroBox 2.2.0 或更新版本，在插件管理页导入 `speedometer-astrobox-plugin/dist/Speedometer GPX.abp`，启用插件并允许所需权限。

## 测速与定位

打开速度计，在室外开阔处等待顶部显示「GPS 已定位」，首页会显示实时速度、海拔、本次平均与本次最高速度。点击速度下方的单位，在 **km/h、m/s、mph** 间切换；点击「详情」查看经纬度、海拔和水平定位精度，点击「返回测速」回到首页。

除录制的 GPX 轨迹外，手表应用不持久保存其他使用数据。平均与最高速度每次打开应用重新统计，不保存到下次使用；未记录时退出再打开也会重置。切换页面、开始或结束 GPX 记录不会重置本次统计，正在记录时熄屏或切入后台再返回会继续累计。平均值包含静止时的有效零速度，排除定位中断时间。字段显示 `--` 表示尚未获取到数据。

## 记录与查看轨迹

1. 首页点击「记录」，按钮变为「结束」，开始每秒保存一个有效 GPS 点。
2. 记录期间可切换页面或熄屏。页面显示约 10 秒后解除常亮，实际熄屏时间和后台持续记录能力由设备系统决定；系统关闭应用会中断记录。
3. 回到首页点击「结束」，等待保存完成，再点击「轨迹」查看文件列表。选择文件可查看轨迹点数、时长和海拔范围；列表未更新时点击「刷新」。
4. 删除单条轨迹：选择文件 →「删除文件」→「确认删除」。点击「取消」放弃删除，「返回列表」返回轨迹列表。

GPX 包含经纬度、时间及设备返回的海拔，新录制及恢复生成的文件采用单行格式，不含回车或换行，以减少文件大小；已完成的旧文件保持原样。定位缺失或超过 5 秒未更新时跳过采样，海拔缺失时不写入该点的海拔字段。新文件名使用记录时的手表时区，列表时间按当前时区显示，GPX 内部时间使用 UTC。异常中断后进入轨迹页会尝试恢复未完成文件。

## 同步与导出到手机

1. 在 AstroBox 连接手表，保持手表上的速度计打开，在插件中选择设备并点击「同步手表列表」。只显示已经结束并保存的轨迹。
2. **单条导出**：点击轨迹上的「下载并导出」，完成后在系统弹窗选择保存位置。已下载文件可在「本地轨迹」点击「导出 GPX」。
3. **批量导出**：点击「下载全部轨迹」，完成后点击「全部导出为 ZIP」，选择手机上的保存位置，再用文件管理器解压到目标文件夹。ZIP 仅包含当前设备已下载完成的本地轨迹。

下载中断后可点击「继续下载并导出」续传。本地轨迹导出与删除不需要连接手表；「取消操作」停止后续处理，已完成的下载、导出或删除不会撤销。

## 删除与存储

| 插件操作 | 删除范围 | 保留的文件 |
| --- | --- | --- |
| 删除手表文件 | 选中的手表轨迹 | 本地副本和已导出文件 |
| 删除手表全部轨迹 | 确认列表中的全部已完成轨迹 | 正在记录的轨迹、本地副本和已导出文件 |
| 删除本地轨迹 | 选中的本地副本及下载进度 | 手表原文件和已导出文件 |
| 删除全部本地轨迹 | 当前设备的全部插件缓存，含未完成下载 | 其他设备缓存、手表原文件和已导出文件 |

所有删除操作都需要确认。手表轨迹保存在应用私有目录；卸载手表应用会清除其中的轨迹。本次测速统计与 GPX 文件删除无关。

## 常见问题

- **一直搜星／没有速度**：确认定位权限已允许，在开阔处等待；超时和一般定位失败会自动重试。设备未开放 GPS 接口时无法使用，模拟器结果不能代替真机定位。
- **轨迹列表为空**：先结束记录并等待保存完成，再刷新列表或重新同步。
- **手表未应答／订阅权限失败**：检查 AstroBox 的设备连接和插件权限，重新打开手表速度计后同步；删除中断后重新同步，确认剩余文件。

手表构建：`npm install` → `npm test` → `npm run build`。插件构建与权限说明见 [插件 README](speedometer-astrobox-plugin/README.md)，通信格式见 [GPX 同步协议](docs/astrobox-gpx-protocol.md)。根目录 [index.txt](index.txt) 指向插件构建产物，用于 [AstroBox 插件上架](https://abox.run/docs/creator-tools/resource-management/plugin-upload)。
